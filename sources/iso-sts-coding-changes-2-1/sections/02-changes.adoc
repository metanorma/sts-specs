== Changes between ed. 1.11 and ed. 2.1

The table below lists every tagging change between Coding Guidelines ed. 1.11
and ed. 2.1, with the affected clause number, the prior and current tagging,
and the SDO(s) the change applies to.

.Changes by clause
|===
| Section in ed. 2.1 | Tagging in ed. 1.11 | Tagging in ed. 2.1 | ISO | IEC

| all
| following NISO STS v.1.0
| following NISO STS v.1.2
| ✓
| ✓

| all
| describing XML from traditional publication chains; differences between ISO and IEC colour-coded
| describing XML from traditional and OSD publication chains; almost full harmonisation between ISO and IEC; legacy tagging moved to annex
| ✓
| ✓

| 3.4
| semantic IDs throughout
| arbitrary IDs will increasingly replace semantic IDs
| ✓
| ✓

| 4.3.2
| —
| new metadata to indicate which edition of the Coding Guidelines an XML file follows
| ✓
| ✓

| 4.4.2
| ISO uses punctuation between elements in `<ref-list>`; IEC does not
| alignment — no more punctuation
| ✓
|

| 4.5.1
| `@content-type` in annexes uses different values at IEC and ISO; can be void or undefined at IEC
| alignment — only values are now `informative` and `normative`
| ✓
| ✓

| 5.1
| various possible formatting options were described
| formatting options are now limited
| ✓
| ✓

| 5.5
| `<named-content content-type="variable">` only used at IEC
| alignment — now also used at ISO
| ✓
|

| 5.7
| `@list-type` can have various values
| limiting options and order of `@list-type`; harmonisation between ISO and IEC
| ✓
| ✓

| ✓
| ✓

| ✓

| ✓

| 6.1
| —
| new information for rendering: tables can now have size attributes
| ✓
| ✓

| IEC does not use `<bold>` in table headers — formatting was supposed to be added on rendering

| ✓

| 6.3
| different options to style tables
| alignment — clear definition of table styling
| ✓
| ✓

| 7.3

| ✓

| 8.2

| ✓

| ✓

| ✓
