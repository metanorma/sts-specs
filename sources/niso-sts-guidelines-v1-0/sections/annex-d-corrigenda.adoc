== Annex D (informative) — IEC corrigenda, interpretation sheets, and software supplements

This annex covers IEC-specific publication types beyond ordinary
amendments:

* Corrigenda — corrections to a published document.
* Interpretation Sheets (ISH) — formal interpretations issued by the
  committee.
* Software supplements — supplements that ship with software components.

Each is encoded as a `<standard>` with distinct
`@publication-type` and section structure.
